The `useCategory` hook has **multiple layers of documentation** to serve different needs:

- **Location**: `src/hooks/useCategory.js`
- **Type**: Embedded JSDoc comments
- **Purpose**: Code-level documentation for developers

  - Self-documenting code

### 2. **🌐 Generated HTML Documentation**
- **Location**: `docs/` folder
- **Generated by**: JSDoc tool
- **Command**: `npm run docs`
- **Purpose**: Web-based documentation for teams

### 3. **📖 README Documentation**
- **Location**: `src/hooks/README.md`
- **Type**: Markdown documentation
- **Purpose**: Project overview and usage guide

### 4. **🧪 Storybook Stories**
- **Location**: `src/hooks/useCategory.stories.js`
- **Type**: Interactive component examples
- **Purpose**: Visual documentation and testing

- **Location**: `src/hooks/useCategory.d.ts`
- **Type**: Type definitions
